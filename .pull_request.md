body: |
  This PR adds a scaffold for an Azure-based CI/CD and GitOps setup using:

  - Azure Kubernetes Service (AKS)
  - Azure Container Registry (ACR)
  - Terraform (state in Azure Storage)
  - Azure Pipelines (CI)
  - Flux v2 (GitOps)

  Contents:
  - infra/terraform/              (backend + modules scaffold)
  - .azure-pipelines/             (CI pipeline config)
  - apps/example-service/         (Dockerfile + k8s manifests + preview overlay)
  - clusters/gitops/              (Flux skeleton)
  - scripts/                      (preview deploy/cleanup scripts)

  Notes & next steps:
  - Ensure you DO NOT bootstrap Flux to manage the same cluster namespaces/resources already managed by your existing GitOps repo.
  - Configure Azure Service Connection and secrets in Azure DevOps before running the pipeline.
  - Terraform modules are a scaffold; review and harden for production.

  Checklist before merge:
  - [ ] Confirm TF backend storage account/container exist or update backend.tf
  - [ ] Configure Azure Service Connection name into azure-pipelines-ci.yml variables
  - [ ] Replace placeholder names (ACR, resource groups) in infra/environments/*.tfvars
  - [ ] Decide if preview feature will be used; adjust pipeline accordingly

  If you want, I can expand Terraform modules and pipeline steps for production readiness in a follow-up PR.
